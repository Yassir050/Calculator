🧮 Python Calculator

A command-line calculator built with Python that performs basic and advanced mathematical operations through an interactive terminal interface.

The project focuses on practicing Python fundamentals such as functions, conditionals, loops, dictionaries, exception handling, lists, and the math module.

✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Modulo
* ** Power
* √ Square Root
* 📜 Calculation History
* 🚫 Division-by-zero protection
* 🚫 Negative square-root protection
* ⚠️ Invalid input handling
* 🔁 Interactive command-line interface

🛠️ Technologies

* Python 3
* math — mathematical functions
* Git & GitHub — version control and project management

🚀 How to Run

1. Clone the repository

git clone https://github.com/Yassir050/Calculator.git

2. Enter the project directory

cd Calculator

3. Run the calculator

python calculator.py

💻 Usage

When the program starts, it displays an interactive menu:

========================
       CALCULATOR
========================
1. Addition       (+)
2. Subtraction    (-)
3. Multiplication (*)
4. Division       (/)
5. Modulo         (%)
6. Power          (**)
7. Square Root    (sqrt)
8. History
9. Exit

Choose an operation, enter the required numbers, and the calculator will display the result.

Example

Choose an option: 1
Enter first number: 15
Enter second number: 5
Result: 20.0

🛡️ Error Handling

The calculator handles several common errors:

* Division by zero
* Square root of a negative number
* Invalid menu options
* Invalid numerical input

Example:

Enter first number: 10
Enter second number: 0
Result: Error: Cannot divide by zero
